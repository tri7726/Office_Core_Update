============================================================
CẨM NANG SỬ DỤNG BỘ DỊCH TÀNG HÌNH OFFICE CORE
============================================================

BƯỚC 1: CÀI ĐẶT HỆ THỐNG
1. Bấm đúp vào file CaiDat.bat trong thư mục này.
2. Đợi màn hình đen chạy xong và hiện chữ "CAI DAT HOAN TAT". Bấm phím bất kỳ để tắt nó đi.
3. (Tùy chọn) Bạn có thể xóa thư mục Office_Core_Update này đi cho sạch máy vì toàn bộ phần mềm đã được cài tự động vào thư mục ẩn của Windows rồi.

BƯỚC 2: SỬ DỤNG TRONG PHÒNG THI
1. Mở Excel lên (mở file bài thi hoặc một file trắng bất kỳ).
   → Công cụ tàng hình SẼ TỰ ĐỘNG CHẠY NGẦM. Không cần bấm nút khởi động nào cả.
2. Khi gặp câu tiếng Anh:
   - Bôi đen câu tiếng Anh.
   - Nhấn phím Ctrl + Shift + C.
   - Chờ khoảng 3-5 giây để nó tự xử lý dịch.
   - Chọn vào một ô trống, nhấn Ctrl + V để dán kết quả tiếng Việt.

CÁC PHÍM TẮT:
   Ctrl + Shift + C  →  Dịch văn bản đang bôi đen (Copy → Dịch → Clipboard)
   Ctrl + Shift + X  →  Ẩn/Hiện cửa sổ công cụ
   Ctrl + Shift + Q  →  Thoát khẩn cấp (xóa dấu vết ngay lập tức)

* BƯỚC KHẨN CẤP (XÓA DẤU VẾT):
1. Chạy file GoCaiDat.bat trong thư mục này.
   → Nó sẽ xóa sạch mọi dữ liệu liên quan đến công cụ khỏi máy tính.

LƯU Ý:
- Công cụ KHÔNG hiện cửa sổ khi khởi động. Đây là hoàn toàn bình thường.
- Để kiểm tra công cụ có đang chạy không: nhấn Ctrl + Shift + X, nếu thấy cửa sổ hiện ra là OK.
- Công cụ tự ẩn khi phát hiện phần mềm giám sát.
